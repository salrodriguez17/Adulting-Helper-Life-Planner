# Adulting Helper: A Beginner Python Life Planner

Created by Sal Rodriguez

## Project Description

Adulting Helper is a beginner-friendly Python program designed to help people make better everyday decisions about money, time, goals, wellness, and weekend planning.

The user answers simple questions about income, expenses, work or study hours, sleep, phone use, stress, energy, and personal goals. The program then gives helpful feedback and creates a simple life plan with practical advice.

## Purpose

The purpose of this project is to show how beginner Python concepts can be used to create a practical and compassionate tool for everyday life planning.
## Beginner Python Concepts Used

- print()
- input()
- variables
- lists
- dictionaries
- loops
- if-statements
- functions
- random choice

## Features

- Money check-in
- Time check-in
- Goal planner
- Wellness check-in
- Weekend plan generator
- Final life plan
- Motivational quote generator

## How to Run the Program

1. Download the file `adulting_helper.py`.
2. Open it in a Python IDE such as VS Code, PyCharm, or IDLE.
3. Run the program.
4. Answer the questions in the terminal.
5. Read your personalized life plan.
